# Live-evidence upgrade gate

`status.json` intentionally says `pending`. The offline successor becomes a public live repair proof only after a sanitized evidence set demonstrates:

1. exact BEFORE baseline and immutable addition-only plan;
2. locked capacitor identity, value, dielectric, voltage, package and pin-to-pad mapping;
3. immediate schematic and PCB readback of only the intended created objects;
4. correct `+5V`/`GND` nets and recomputed local distance;
5. save, close, reload and independent second readback;
6. ERC, connectivity, containment and strict DRC results;
7. fresh Prototype review closing only the target blocker;
8. no loss or mutation of unrelated BEFORE objects.

Publish summaries and hashes, not raw project files, private logs, screenshots or internal transaction identifiers.
